# Bozeman Engineering

We build **[Daedalus](https://www.drupal.org/project/daedalus)**, the
open source human+AI page builder for Drupal, GPL-2.0-or-later,
developed in the open on drupal.org.

- **Code and issues:** https://www.drupal.org/project/daedalus
  (this org carries a [read-only mirror](https://github.com/Bozeman-Engineering/daedalus))
- **Install:** the [Daedalus recipe](https://www.drupal.org/project/daedalus_recipe)
- **Who:** [Tim Bozeman](https://www.drupal.org/u/tim-bozeman) and [Lily Bozeman](https://www.drupal.org/u/lillian-bozeman)
- **Site:** https://bozeman.engineering
- **Talk:** BADCamp 2026, Oakland, right after the keynote

Sponsorship funds the work that has no client: the issue queue, core
compatibility, docs, accessibility and tests.
